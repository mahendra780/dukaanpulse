# DukaanPulse documentation

Six documents describe the whole product. Read them in this order.

| # | Document                                        | Answers the question                                          | Best for                        |
| - | ----------------------------------------------- | ------------------------------------------------------------- | ------------------------------- |
| 1 | [PRD](01-PRD.md)                                 | What are we building, for whom, and why?                      | Everyone, in plain language     |
| 2 | [TRD](02-TRD.md)                                 | How is it built, and which technical rules apply?             | Developers                      |
| 3 | [App Flow](03-APP-FLOW.md)                       | Which screens exist, and how does a person move through them? | Product, design, testing        |
| 4 | [UI/UX Design Brief](04-UIUX-DESIGN-BRIEF.md)    | How must it look and feel?                                    | Designers, front-end developers |
| 5 | [Backend Schema](05-BACKEND-SCHEMA.md)           | What data is stored, how, and how does login work?            | Back-end developers             |
| 6 | [Implementation Plan](06-IMPLEMENTATION-PLAN.md) | In what order is it built, and what is left?                  | Whoever builds next             |

## Keeping them true

- Change the document **in the same change** as the code.
- If two documents disagree, the code wins. Fix the document.
- Do not add a seventh document for a topic one of these already covers. Add a section instead.
